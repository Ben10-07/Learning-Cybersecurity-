## My Learning Process

I follow this process while creating these notes:

```text
TryHackMe Room
      ↓
Understand the Room
      ↓
Use ChatGPT to clarify difficult concepts
      ↓
Create personal notes in Hindi/Hinglish
      ↓
Convert and organize the notes into English
      ↓
Review and add them to GitHub
```

### How I Use ChatGPT

I use ChatGPT as a learning assistant to:

* Understand difficult concepts in simple Hindi/Hinglish
* Clarify technical terms and confusing sections
* Break down commands and their purpose
* Check my understanding of concepts
* Help organize my personal notes
* Convert my Hindi/Hinglish notes into clear English

The goal is **understanding the concepts first**, rather than simply copying answers.

## About the Notes

Most of the notes are based on what I learned from the respective rooms and my own understanding.

Since some notes are translated or rewritten from my personal Hindi/Hinglish notes into English, **minor wording or translation mistakes may exist**.

I may also update the notes later when I learn something more accurate or gain a better understanding of a topic.

## Important Disclaimer

This repository is created for **educational and cybersecurity learning purposes**.

Commands and techniques should only be used on:

* TryHackMe labs
* CTF environments
* Personal systems
* Systems where I have explicit authorization to test

Unauthorized access or testing of systems is not the purpose of this repository.

## Why I Am Making This Repository

I want to document my cybersecurity journey, track what I have learned, and build a reference that I can return to for revision.

This repository is a record of my **learning process**, not a claim that everything here is perfect.

> Learn → Understand → Practice → Document → Improve
